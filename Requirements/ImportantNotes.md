# Installation guide
Place the 3 dll files on the same directory of the program.
Run vc_redist.x64.exe to install Microsoft Visual C++ Redistributable (if you haven't installed before yet).

# 安装教程（中文）
将3个DLL文件复制在与程序相同的文件夹。
运行vc_redist.x64.exe来安装Microsoft Visual C++可再发行程序包。
